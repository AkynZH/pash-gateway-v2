# PASH Gateway

Универсальный шлюз для генерации UI-компонентов с использованием LLM, обеспечивающий детерминизм, отказоустойчивость и корпоративный уровень управления.

## 🏗 Архитектура

Монорепозиторий состоит из следующих ключевых модулей:

- **`apps/gateway`**: Основной Express-сервер, маршрутизация, аутентификация, Circuit Breaker и управление провайдерами LLM.
- **`packages/state-engine`**: Ядро управления состоянием. Построение и валидация Component Tree, сессионное хранилище, механизм Time Travel Replay.
- **`packages/billing`**: Модуль учета токенов, подсчета экономии и квотирования.
- **`packages/cli`**: GitOps CLI для валидации схем и тестирования детерминизма LLM (`@pash/cli`).

## 🚀 Ключевые возможности (v2.0+)

### 1. Governance Layer (Управление доступом)
- **Component Blacklist/Whitelist**: Блокировка или разрешение конкретных UI-компонентов на уровне сессии.
- **Max Lines Limit**: Жесткое ограничение объема генерируемого кода (`effectiveLimit = Math.min(lineLimit, governance.maxLines)`), предотвращающее бесконечную генерацию.

### 2. Observability & Replay Engine (Наблюдаемость и откат)
- **4 уровня логирования**: Raw, Constraint, PASH, Snapshot.
- **Time Travel Replay**: Эндпоинт `GET /v1/presentation/replay/:id` позволяет полностью воссоздать дерево состояний на любом историческом шаге (`targetStep`) для отладки или аудита.

### 3. Systemic Webhooks (Системные уведомления)
Асинхронная отправка (fire-and-forget) событий во внешние системы:
- `pash.error`: Критические ошибки генерации или валидации.
- `pash.limit.exceeded`: Превышение лимитов токенов или строк кода.
- `pash.provider.failover`: Автоматическое переключение на резервный LLM-провайдер при сбое основного.

### 4. GitOps CLI (`@pash/cli`)
Инструменты для CI/CD пайплайнов:
- `pash check-schema <old> <new>`: Обнаружение Breaking Changes в схемах компонентов (удаление полей, смена типов).
- `pash consistency-score <prompt> [--runs N] [--temp T]`: Оценка детерминизма промптов путем многократной симуляции генерации.

## ⚙️ Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск всех сервисов в режиме разработки
npm run dev

# Запуск тестов монорепозитория
npm test
```

## 🛡 Безопасность и отказоустойчивость
- **Circuit Breaker**: Автоматическое отключение неисправных LLM-провайдеров и мгновенный failover с повторной инъекцией PASH-промпта.
- **PromptInjector Protection**: Защита от двойной инъекции системного промпта.
- **State Isolation**: Полная изоляция сессий и атомарное обновление дерева компонентов.
